## Selected work

### [Budget App for Guinayangan SHS Students](https://github.com/Soozu/budget-application)

An offline-first mobile budget tracker designed for senior high school students. It helps users record allowances and expenses, understand spending habits, and work toward savings goals.

`React Native` `Expo` `AsyncStorage` `JavaScript`

### [RFID Student Attendance System](https://github.com/Soozu/RFID)

A web-based attendance platform with RFID card management, real-time logging, dashboards, analytics, and Excel exports for educational institutions.

`PHP` `JavaScript` `MySQL` `RFID`

### [STOVE Account Generator](https://github.com/Soozu/stove-account-generator)

A Windows-focused Python automation tool with temporary email integrations, local account history, export controls, system diagnostics, and release update checks. Built for educational use.

`Python` `Automation` `CLI` `Windows`

### [Tournament Manager](https://github.com/Soozu/Tournamenr-manager)

A tournament operations system covering team registration, bracket generation, leaderboards, game-master controls, PDF generation, and email notifications.

`PHP` `MySQL` `JavaScript` `TCPDF` `PHPMailer`
